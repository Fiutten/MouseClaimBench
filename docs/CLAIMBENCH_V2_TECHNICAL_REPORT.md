# ClaimBench v2 technical report

Date: 2026-07-31

## Thesis

ClaimBench v2 is an executable claim-auditing framework for scientific AI
studies. Its purpose is not to maximize prediction, fact-checking accuracy, or
causal-discovery performance. Its purpose is to decide which scientific claims
are authorized, blocked, or kept uncertain given the available evidence
artifacts.

The defensible contribution is the separation of:

- prediction;
- reproducibility;
- topology specificity;
- direction;
- local structure-function association;
- causal evidence;
- digital-twin wording;
- uncertainty;
- manuscript wording;
- LLM-assisted claim extraction;
- release reproducibility.

## LLM layer boundary

The LLM layer is deliberately non-authoritative. In the current reproducible
package no LLM API is called. The default extractor is deterministic and only
produces candidate claims and conservative wording suggestions.

The final decision remains with ClaimBench artifacts and DSL contracts.

Allowed statement:

> ClaimBench v2 includes an LLM-ready claim extraction layer in which LLMs may
> propose candidate claims, while executable evidence contracts remain the only
> authority for claim authorization.

Blocked statements:

- ClaimBench v2 uses an LLM to verify scientific truth.
- ClaimBench v2 is a state-of-the-art scientific fact-checker.
- LLM-generated claims are accepted without executable evidence.

## Reviewer threat model

The current threat model covers:

- rule-table criticism;
- threshold arbitrariness;
- synthetic overfitting;
- causal overclaiming;
- manuscript wording drift;
- LLM authority drift;
- hidden uncertainty.

All critical threats currently pass with explicit claim boundaries.

## What is still not claimed

The package does not support:

- complete mouse-brain digital twin claims;
- causal mechanism claims from observational MICRONS evidence;
- Sensorium or SciFact state-of-the-art claims;
- causal-discovery performance claims on Tuebingen;
- automatic peer review;
- universal scientific claim verification.

## Best paper framing

The strongest current framing is:

> Executable claim governance for scientific AI: a reproducible framework that
> binds manuscript-level claims to non-compensatory evidence contracts, external
> overclaiming controls, reviewer threat models, and optional non-authoritative
> LLM-assisted claim extraction.

This is stronger than a neuro-only benchmark and safer than a predictive-model
paper.
