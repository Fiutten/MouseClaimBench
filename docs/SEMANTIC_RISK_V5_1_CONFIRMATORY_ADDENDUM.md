# Semantic risk v5.1 confirmatory addendum

Version 5 failed because no scalar threshold jointly controlled the event of any
false authorization across six claim families while retaining non-zero use. The
failure is preserved in `results/timegraph_v5_confirmation`.

An allowed development analysis then evaluated each claim family separately.
Only `topology_specific` had a non-degenerate development certificate. Version
5.1 therefore fixes that family and its development threshold before accessing
new outcomes. This narrowing is disclosed and cannot be described as a
confirmation of the original global hypothesis.

The risk lock, final evaluation, and OOD stress use 100 new seed bundles each.
No v5.1 threshold fitting is permitted. The final split is generated only after
the risk lock passes. The primary event is whether a bundle contains at least
one false topology-specific authorization.

This design can support one narrow conclusion: a fixed semantic authorizer can
control topology-specific false authorization within the declared TimeGraph
mixture. It cannot support prediction, direction, mechanism, causality, real
hydrological transport, neuroscience, or universal calibration claims.
