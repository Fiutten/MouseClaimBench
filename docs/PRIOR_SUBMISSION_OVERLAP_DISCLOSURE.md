# Prior-submission overlap disclosure

## Purpose

MouseClaimBench is a follow-up methodological study. The earlier MouseBrainBench
manuscript and its frozen supporting commit must remain separate. This note
records the overlap that should be disclosed to the Knowledge-Based Systems
editor and prevents the second paper from presenting reused artifacts as new
prospective data.

## Reused material

The second study reuses bounded result packages for Allen VBN, Static Sensorium,
Dynamic Sensorium, IBL, and MICRONS. It does not claim that these five source
analyses are newly collected independent replications. The MICRONS analysis is
extended with directed dyadic covariance and simultaneous node-label
permutation, but it remains one volume with internal windows.

## Distinct technical contribution

The second study adds material that is not the central contribution of the
first manuscript:

- profile-v2 authorization with complete multi-deficit output
- observation admissibility for every passing evidence block
- RDF/PROV-O representation and external SHACL execution
- exact Python/ASP domain conformance and separate external SHACL structural conformance
- eight relational package-integrity controls
- 360 controlled attacks and leave-one-control-out ablation
- six formal profile-relative properties over 10,000 packages
- scalability to 10,000 packages and 5,000 artifacts
- two DANDI protocols frozen before numerical asset access
- a standards/prospective release gate with explicit prohibited claims

## Submission action

Before submission, disclose the related MouseBrainBench manuscript and provide
it to the editor if the submission system requests related work. If it has a DOI
or stable preprint by that time, cite it in the article and replace the generic
phrase `preceding MouseBrainBench study` with the formal citation. The cover
letter should state that the five retrospective packages are reused and that the
standards, integrity, attack, ablation, formal, scalability, and prospective
DANDI results constitute the new contribution.
