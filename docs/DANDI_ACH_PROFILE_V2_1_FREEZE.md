# Prospective DANDI acetylcholine profile-v2.1 freeze

This protocol freezes a new artifact-grounded application before any numerical
asset value is opened. Selection uses only public DANDI metadata for published
Dandiset `001176`, version `0.260610.2204`.

The independent unit is the mouse. The primary endpoint, model, temporal split,
comparators, quality exclusions, minimum subject count, thresholds, and claim
boundary are fixed in
`configs/benchmarks/dandi_ach_profile_v2_1.yaml`. A negative outcome is retained
without endpoint or threshold repair.

The application evaluates prospective profile behaviour, not a new biological
discovery. The dataset title already states an acetylcholine-prediction result.
The admissible contribution is therefore restricted to locked artifact
authorization on a previously unused mouse resource.
