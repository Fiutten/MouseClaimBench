\section{Research Contributions}
\label{sec:contributions}

MouseClaimBench transforms heterogeneous computational results into explicit knowledge about the claims they can and cannot support. It does not assign a global score to a model or manuscript. It evaluates each claim against a versioned domain profile and preserves the complete path from source observation to conclusion. The paper makes five contributions:

\begin{itemize}
    \item \textbf{A versioned mouse-brain claim knowledge profile.} The externalized \ac{yaml} profile defines ten claim types, twenty claim-to-evidence requirements, five evidence states, five inference conclusions, and five prioritized rules. Validation rejects duplicate claims, repeated requirements, incomplete conclusion coverage, and ambiguous rule priorities.

    \item \textbf{A provenance-preserving evidence fact model.} Every fact retains original-scale observations, the predicate that produced its status, a rationale, and its source artifact. Missing evidence is represented explicitly rather than converted into a failed or zero-valued measurement.

    \item \textbf{An explainable non-compensatory inference engine.} A failed mandatory block vetoes dependent wording. Review, uncertainty, and protocol scope remain distinct conclusions. Each inference records the fired rule, witness blocks, evaluated rule sequence, source facts, and SHA-256 profile identity.

    \item \textbf{A multi-level validation strategy.} An independently labelled structural-equation oracle measures false authorization and false rejection. Exhaustive tests evaluate all 625 evidence-state assignments for the mechanistic claim. A conformance audit reproduces 40 frozen decisions from four heterogeneous mouse-brain cases and verifies 40 complete traces.

    \item \textbf{A reproducible KBS release with external failure controls.} SciFact distinguishes retrieval from support inference, while Tuebingen distinguishes association from causal direction. The release gate checks required artifacts, expected outcomes, clean revisions, profile identity, and unresolved scientific claim boundaries without requiring an unclaimed human-effect study.
\end{itemize}

These contributions support a bounded result. MouseClaimBench implements and evaluates a knowledge-based validation method for computational mouse-brain claims under the declared profile. It does not establish cross-domain empirical generality, biological truth, external biological replication, causal-discovery performance, improved human review, or a complete mouse-brain digital twin.
