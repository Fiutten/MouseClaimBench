\section{Conclusions and Future Work}
\label{sec:conclusions}

MouseClaimBench provides an integrity-aware knowledge-based method for authorizing bounded claims from computational mouse-brain evidence. Its contracts bind graph conformance, package integrity, domain semantics, and category-complete non-compensatory deficits. Each decision is tied to a named profile and retains every violated category with an actionable witness.

The evaluation separates acquisition, specification verification, controlled threats, and empirical application. The ledger covers all 60 claim--evidence relations and 22 predicate contracts without claiming external consensus. Python and the separately implemented \ac{asp} path agree across 5,677 domain cases, external \ac{shacl} recovers the expected structural outcomes, and the final gate reproduces all eight states of $S\land A\land I^{\mathrm{clean}}$. One-edge perturbation and counterfactual repair establish implementation conformance and explanation fidelity relative to profile v2, not scientific completeness.

The integrity evaluation blocks all 2,550 attacked packages under the declared families, while all 20 coherent forgeries expose the need for external trust anchors. One prospective DANDI protocol retains an availability refusal and another authorizes only population-response prediction across 32 mice. Dependence-aware \ac{microns} inference confirms one local observational association in two pre-fixed hold-outs. No case authorizes causality, external biological replication, whole-brain coverage, or a complete entity-specific mouse-brain digital twin.

Future work requires independent profile assessment, human evaluation of traces, signed attestations, adaptive attacks, and externally registered endpoints. The current conclusion remains narrower: prediction, reproducible execution, and graph validity cannot compensate for missing scientific evidence or incoherent provenance under the declared profile.
