\section{Conclusions and Future Work}
\label{sec:conclusions}

MouseClaimBench provides an integrity-aware knowledge-based method for authorizing bounded scientific claims from computational mouse-brain evidence. Its authorization contracts jointly bind graph conformance, package integrity, domain evidence semantics, and complete non-compensatory deficits. Authorization requires every mandatory block and every integrity control to pass. The result is tied to a named profile and includes all deficits, witnesses, artifact identities, and protocol revisions.

Python and \ac{shacl} agree on all 5,497 structural contract cases, while the independent \ac{asp} path agrees on its 262-case deterministic subset. Six formalized properties and outside-profile closure show no violation in 55,031 checks. Under the declared deterministic threat model, the full integrity gate blocks all 360 attacked packages. A profile-only system authorizes every attacked package and a hash-only baseline authorizes 280. Each leave-one-control-out ablation reintroduces false authorization. These results establish implementation consistency and controlled-attack resistance under the declared profile. They do not establish the profile as a consensus taxonomy.

External applications preserve the same boundaries. One prospective DANDI protocol remains negative because its frozen subject requirement is unavailable. A second protocol authorizes only population-response prediction across 32 mice. Dependence-aware \ac{microns} inference authorizes one local observational structure--function association. No evaluated case authorizes a causal mechanism, external biological replication, whole-brain coverage, or a complete entity-specific mouse-brain digital twin.

Future work should obtain independent assessment of the profile relations, evaluate whether complete traces improve human review decisions, and externally preregister endpoints across laboratories and animals. The integrity model should add signed attestations, archive trust policies, and adaptive provenance attacks. New domain profiles should be introduced only with their own evidence vocabulary, external cases, and content-validation process. The immediate conclusion remains narrower and testable: predictive accuracy, reproducible execution, and valid graph structure cannot compensate for missing scientific evidence or incoherent provenance.
