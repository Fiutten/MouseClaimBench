\section{Experimental Protocol}
\label{sec:experiments}

The experimental protocol evaluates ClaimBench as a decision-support mechanism. Therefore, the experiments are not organised as a leaderboard, nor as a comparison against specialised predictive systems. They are organised around decision questions: whether the gate implements the intended semantics, whether external controls expose overclaiming risks, whether LLM assistance remains bounded, whether each component has non-redundant value, and whether the release package can be inspected by a reviewer.

This separation is important because the object of evaluation is not a model output alone. The object is the relation between evidence and scientific wording. For this reason, each experiment defines an audit question, an artifact family, and an acceptance criterion before reporting numerical results. The first block of experiments evaluates internal semantics. Synthetic known-truth configurations define the evidence dimensions that are present or absent for each claim family. The purpose is not to simulate a real scientific domain. The purpose is to verify that the gate behaves as declared. A mechanistic claim must fail if topology or direction is missing. A causal claim must fail if causal evidence is absent. A predictive claim can pass without being promoted to mechanism. The primary acceptance criterion is therefore strict: unsupported claims must not be authorized as supported.

The second block evaluates robustness of decision thresholds and uncertainty handling. A decision-support tool cannot hide its sensitivity behind a single chosen threshold. The threshold sweep therefore records safe regions, dangerous regions, and borderline cases. The uncertainty gate then checks whether unstable cases remain uncertain instead of being forced into binary support. This block is not designed to prove universal calibration. It is designed to make calibration limits visible to authors and reviewers.

The third block uses external controls. SciFact tests whether scientific claim-evidence handling can be audited outside the original neurocomputational setting. The experiment separates document retrieval, rationale agreement, support classification, abstention, and overclaiming risk. Tuebingen tests a different failure mode: the promotion of association or correlation into causal direction. The aim is diagnostic. ClaimBench is not optimized as a SciFact system or as a causal-discovery method. It uses both resources to verify that claim authorization is stricter than ordinary evidence proximity or correlation.

The fourth block evaluates manuscript and LLM boundaries. The manuscript audit checks whether active project texts contain wording that violates executable claim contracts. The LLM audit checks whether candidate claim extraction can be included without changing the authority structure of the framework. The reproducible configuration uses deterministic extraction and records whether an external LLM file was loaded. In every case, candidate generation remains separate from claim authorization.

The fifth block evaluates component necessity and release integrity. Component ablation removes or weakens one safeguard at a time. The tested removals include correlation-only evaluation, weighted-score compensation, removal of topology and direction blocks, removal of uncertainty, lexical shortcutting, causal authorization from correlation, and removal of manuscript auditing. Release integrity is then checked through the reproduction manifest and the release gate. These two experiments answer different reviewer concerns. Ablation answers whether the rules have value. Release integrity answers whether the described artifact can actually be inspected.

The protocol deliberately separates design from outcome. This prevents the experimental section from becoming a results narrative and avoids circular justification. The numerical results in the next section are interpreted only under the boundaries declared here. A positive SciFact control does not imply state-of-the-art scientific fact verification. A positive Tuebingen control does not imply causal discovery. A clean manuscript audit does not imply scientific novelty. It only means that the current wording respects the executable claim boundary.
