\section{Conclusions and Future Work}
\label{sec:conclusions}

MouseClaimBench provides a standards-aware knowledge-based method for authorizing bounded scientific claims from computational mouse-brain evidence. It separates graph conformance, package integrity, and domain evidence requirements. Authorization requires every mandatory block and every integrity control to pass. The result is tied to a named profile and includes all deficits, witnesses, artifact identities, and protocol revisions.

The implementation agrees across Python, \ac{asp}, and \ac{shacl} on 5,497 contract cases, while 55,031 formal-property checks show no violation. The full integrity gate blocks all 360 controlled attacks. A profile-only system authorizes every attacked package and a hash-only baseline authorizes 280. Each leave-one-control-out ablation reintroduces false authorization. These results establish a substantial knowledge-engineering contribution under the declared semantics and threat model.

External applications preserve the same boundaries. One prospective DANDI protocol remains negative because its frozen subject requirement is unavailable. A second protocol authorizes only population-response prediction across 32 mice. Dependence-aware \ac{microns} inference authorizes one local observational structure--function association. No evaluated case authorizes a causal mechanism, external biological replication, whole-brain coverage, or a complete entity-specific mouse-brain digital twin.

Future work should obtain independent assessment of the profile relations, evaluate whether complete traces improve human review decisions, and test preregistered endpoints across laboratories and animals. The integrity model should add signed attestations, archive trust policies, and adaptive provenance attacks. New domain profiles should be introduced only with their own evidence vocabulary, external cases, and content-validation process. The immediate conclusion remains narrower and testable: predictive accuracy, reproducible execution, and valid graph structure cannot compensate for missing scientific evidence or incoherent provenance.
