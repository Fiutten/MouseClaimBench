\section*{Data and Code Availability}
\label{sec:data-code-availability}
The source code, knowledge profiles, tests, frozen protocols, lightweight result artifacts, and manuscript are maintained in the public MouseClaimBench repository at \url{https://github.com/Fiutten/MouseClaimBench}. The software snapshot used for this revision is released as tag \texttt{v0.12.1} at \url{https://github.com/Fiutten/MouseClaimBench/tree/v0.12.1}. The regenerated revision artifacts were executed from clean source commit \texttt{3746a46b58666a71a79619072dfe7663e3671348}. Raw Allen, Sensorium, IBL, MICRONS, and DANDI data remain governed by their providers and are not redistributed. The prospective artifact manifests retain public identifiers, versions, sizes, and official hashes. Every reported result is linked to a recorded Git revision, and artifacts marked as dirty are excluded from the release gate. A persistent DOI has not been assigned, so the repository and tagged commit are reported without implying DOI-backed archival permanence.
