\label{sec:data-code-availability}

Raw Allen, Sensorium, Tuebingen, SciFact, and MICRONS data are governed by their original providers and are not redistributed. Every reported result is linked to a recorded Git revision. Artifact files marked as dirty are excluded from the release gate.
