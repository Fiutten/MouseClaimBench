\section*{Data and Code Availability}
\label{sec:data-code-availability}
The source code, contracts, tests, lightweight result artifacts, and manuscript are maintained in the public MouseClaimBench repository at \url{https://github.com/Fiutten/MouseClaimBench}. Raw Allen, Sensorium, Tuebingen, SciFact, and MICRONS data are governed by their original providers and are not redistributed. Every reported result is linked to a recorded Git revision. Artifact files marked as dirty are excluded from the release gate.
